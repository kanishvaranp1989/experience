If you are successfully logged in, you have virtually travelled across below services,

  • AWS Cognito: Auth service to manage user profiles
  • AWS EC2: Compute service where this flask app is running
  • Python Flask: Web framework
  • Bootstrap UI: Frontend framework

Please click below button to get the download link for Kanish's resume. It is stored as PDF in AWS S3. The download link will be valid for 45 minutes. Please see how the resume link is generated:

  • AWS Api gateway:Entrypoint for any request. Access token gets generated after login. In api gateway request gets authorized against id token for accessing aws backend services
  • AWS Lambda: Request receives from ui. This service generates presigned url for the resume stored in AWS S3
  • AWS S3: Object storage. Stores the resume as a PDF file
  • AWS Cloud watch:Observability service to monitor and log application performance. Your actions are logged here.
  • Route 53: DNS service to map domain name to AWS resources. However it is not used here for reducing the cost
  • CloudFront: CDN service to serve content globally with low latency. This is also not used here as it is not required for this simple application.
